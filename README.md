# Turky

Desktop app for sending images and GIFs to a TURZX USB display (Tauri + React + Rust).

**Status:** early development. APIs, device support, and performance will change. Expect rough edges.

## Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (stable)
- [Bun](https://bun.sh) (used by Tauri `beforeDevCommand` / `beforeBuildCommand`)
- OS deps for [Tauri 2](https://v2.tauri.app/start/prerequisites/)

| OS | Extra notes |
| --- | --- |
| Windows | MSVC Build Tools + WebView2. USB needs a working WinUSB/libusb setup for the device. |
| macOS | Xcode Command Line Tools. May need USB access permission for the device. |
| Linux | WebKitGTK / GTK build deps from the Tauri docs. Install `libusb` (e.g. `libusb-1.0-0-dev`). |

## Setup

```bash
git clone <repo-url>
cd Turky
bun install
```

## Run

Real USB device (discovered at startup):

```bash
bun run tauri dev
```

Virtual display (no hardware). Width and height must match your media:

```bash
bun run tauri dev -- -- --virtual-device --width=480 --height=1920
```

Then pick a PNG/JPEG/WebP/GIF in the main window.

## Project layout

- `src/` — React UI
- `lib/` — Rust / Tauri backend (USB + virtual adapter)

## Notes

- Only the TURZX 8.8 (VID `0x1CBE` / PID `0x0088`) is supported as a real device today.
- Virtual mode is for local testing when you do not have the hardware plugged in.
